UPTM-SLS V4 ENHANCEMENTS
========================

Changes included:
1. Added a library study photo to the login page.
2. Added a five-book catalogue showcase to the dashboard.
3. Added a clear red overdue penalty notice on Dashboard and My Borrowings when a user has overdue books.
4. Added five more sample Computer Science / IT books in database/upgrade_v4_add_5_books.sql.
5. Kept the existing blue + red theme and current functionality.

For an EXISTING InfinityFree website:
- Replace login.php
- Replace dashboard.php
- Replace borrowings.php
- Replace assets/css/style.css
- In phpMyAdmin, select your existing database and import database/upgrade_v4_add_5_books.sql ONCE.

IMPORTANT:
Do NOT replace config/database.php on your live InfinityFree site. Keep your current online database credentials.
Do NOT import the original uptm_sls.sql again because it contains DROP TABLE statements and may reset existing data.
